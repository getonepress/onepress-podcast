# onepress-podcast — ClawHub Skill

A ClawHub/OpenClaw skill that delegates podcast production to [OnePress](https://www.getonepress.com).

**Requires `ONEPRESS_API_KEY`** — podcast synthesis runs on OnePress infrastructure.
Create a key at getonepress.com → app → Settings → Account → API keys.

See `SKILL.md` for the full contract (REST + MCP, polling, follow-ups, errors).

```bash
clawhub install onepress-podcast
```
